I created a dashboard to load sales data and run predefined and
custom analyses.

Individual requirements: 2 (data summary) and 10 (save and display results).

product) and 9 (fill missing pivot-table values with column means).

# Evidence or Documentation of testing
I tested the final version with test_finalversion.py. The tests check
data loading and summaries, row selection, the predefined and custom analyses,
invalid user input, and saving and displaying results. All tests passed.

# How I used AI on this assignment
I used AI for help when I came across things I did not understand. Some of the
harder parts were using pivot tables to group the sales data, calculating each
product's percentage of its region's total, filling missing pivot-table values
with averages, and testing the menu's user input. I asked AI to explain
these ideas and walk me through what the code was doing. If I did not understand
an explanation, I asked for a simpler one or for an example using things I
learned in class. I worked through the assignment in smaller parts and tested
the code as I went. AI helped teach and guide me through the parts I did not
know.

# Flask Quiz Game
Kaumualii Clemente

I created a web quiz using questions from Assignment 1.

Individual requirements: 2 (top-10 leaderboard) and 10 (responsive design).

Additional requirements: 8 (progress bar) and 9 (review missed questions with
explanations).

# Evidence or Documentation of testing
I tested the app with `test_quiz_app.py`. The tests check the quiz, API,
leaderboard, input validation, and responsive styling. All six tests passed.

# How to run the app
Install Flask, then run `python3 finalversion.py` from the `assignment 3`
folder. Open http://127.0.0.1:5001 and click **Start Quiz**. Keep the terminal
open while playing. Run `python3 -m unittest -v` to run the tests.

# How I used AI on this assignment
I used AI for help when I came across parts I did not understand. Some of the
harder parts were keeping quiz answers in a Flask session, returning JSON from
REST API routes, sorting and saving the top-ten scores, and making the pages
responsive. I asked AI to explain these ideas and walk me through what the code
was doing. I worked through the assignment in stages and tested it as I went.
